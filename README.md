# 📖 Curso Online de Crisma – Estilo Duolingo (2026)

Bem-vindo ao **Curso Online de Crisma**!  
Este projeto foi desenvolvido para oferecer uma experiência gamificada e responsiva, inspirada no estilo do Duolingo, para preparar jovens e adultos para o sacramento da Crisma em 2026.

---

## ✨ Funcionalidades

- 🎯 **Lições curtas e objetivas** com leitura bíblica, resumo e glossário
- 📝 **Quiz de 20 perguntas** ao final de cada lição
- 📊 **Testes de 10 perguntas** a cada 2 lições
- 🏆 **Pontuação e conquistas** (XP, streak diário, badges)
- 📱 **Responsivo**: funciona em desktop e celular
- 🌐 **Hospedado no GitHub Pages**
